# ADR-010：任务校验与生成预算

日期：2026-10-02。状态：已接受的实施决策；尚未实施部分须按对应里程碑验收。

## 决定

scenario validate 执行结构、门卡依赖/门必经约束及完整 Core 求解。M2 已实现生成版本 facility-generation/1；PCG32 命名流 map/objects/mission。候选参考路径默认上限128，有限重试默认16、允许1–64。派生输入为 UTF-8 generation-rng/1 + NUL + 流名 + NUL + UInt64十进制seed，SHA-256摘要前8字节/随后8字节按little-endian作为PCG参考初始化的state/sequence。

## 理由

先构造任务拓扑，防止布局合法却不可解或门卡任务被绕过；派生编码无歧义。
