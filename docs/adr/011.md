# ADR-011：超时、限制与错误边界

日期：2026-10-02。状态：已接受的实施决策；尚未实施部分须按对应里程碑验收。

## 决定

握手5秒，发送观测与等待动作共享30秒期限；正常退出宽限1秒、强制终止等待3秒；Agent行内容64KiB、深度32、stderr尾部64KiB、订阅队列128个envelope。JSONL允许合法单行JSON空格；多余/重复/未知字段和错请求ID拒绝。Observer消息建议128KiB，Scenario文件64KiB；M3/M4核验最坏编码大小和有界读写。

## 理由

错误不被静默翻译为wait，避免无界内存与永久挂住。

## 验证与重新评估

M3已实测本机Windows会话、超时/取消和Agent根进程退出；Linux与完整后代/孤儿进程清理留作M6发布门槛。M4验证记录提交与拥塞；参数可配置但不改变游戏tick。M3宿主发出的Agent消息也限制64KiB，大视野超限在动作进入Core前拒绝。
