## 角色

- **主代理（高级审查）**：需求拆解、接口/验收标准设计、任务书撰写、产物审查、修错补漏、真实构建与运行、里程碑与文档定稿。主代理不再执行大块"体力型"实现。
- **子代理（廉价额度）**：按任务书产出单一、边界清晰的产物（新文件、单文件修复、只读审查、文档草稿）。

## 硬性规则

1. **子代理自报不等于验收**：任何产物都必须由主代理实际 `dotnet build`、运行对应验收程序或命令后才算通过。AGY 类子代理只能写文件，其"已完成/已通过"一律视为未验证。
2. **单一产物边界**：一个任务只允许新建/修改明确列出的文件，禁止改动 csproj、solution、他人正在改的文件；需要接线时由主代理做。
3. **不做超出范围的框架**：零第三方 NuGet 依赖（除非任务书明确批准并说明理由）。
4. **不做无证据的断言**：产物里的注释、文档不得声称未实测的行为。
5. **额度操作**：长耗时验证（种子扫描、性能基准）放后台作业，不要占用对话轮次；优先跑目标项目而不是整套。
6. **失败产物处理**：编译错误、断言错误、语义偏差由主代理直接修，不来回要求子代理重做（重做成本 > 主代理修错成本）。必要时把"已知易错点"写进下一份任务书。

## 审查清单（每次交付逐条过）

- 编译：`dotnet build AgentGame.slnx -c Release` 0 警告 0 错误（并发占用 dll 时的 MSB3026 重试警告可忽略）。
- 边界：新文件是否被真实引用/注册；是否有死代码；是否越权修改其它文件。
- 行为：真实命令跑过；失败路径（超时、取消、非法输入、I/O 失败）有对应检查。
- 契约：退出码、stdout/stderr 分流、JSON 字段与既有文档一致。
- 不夸大：文档/注释与实现逐条对齐；把"未验证""未接线"显式写出来。
- 记录：新增/修改文件与命令结果写入 `docs/parallel-work.md` 或对应里程碑文档。
