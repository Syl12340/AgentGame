# M0–M1 验收记录

结论：M0 的契约、工程、固定场景与 ADR，以及 M1 的纯 Core 已通过本轮 Windows 开发验收。M2–M6 未实施，不代表 v0.1 发布完成。

## 环境与版本

- 全局 SDK：10.0.401，global.json 精确固定、rollForward=disable。
- 构建：net10.0 / Release，nullable 与编译警告作为错误启用。
- Core 规则：facility-zero/1；规范编码：core-state/1。
- 传输/文件契约：agent/1、observer/1、scenario/1、replay/1。
- 四个生产项目、三个无第三方依赖的 console 验收项目。

## 已修正问题

DSH 初稿 StepBatch 使用完整 state 替换，随后主代理固定为显式 patch；nullable 清空字段强制输出。修正不必要的包络空白拒绝和共享 actions 数组；回放保存完整 status envelope 并使 base_seq=0 后的 seq 为 1/2；Core hash 改为动作后向量，异常 footer/result 与真实规则一致。协议形状已更新规范与 tests，不把格式 fixture 当作已实现播放器。

## 限制与下一阶段

当前 Runtime 为工程空壳；CLI 仅 help/version。生成器、完整求解器、Agent 子进程、Observer 投影/reducer/Hub、记录文件读写、replay/verify 命令、TUI、人工模式均未实现。协议 DTO 的数组由后续 Runtime 负责深复制或冻结后发布，当前不是线程安全消息总线。

Linux 对照、进程树清理、慢订阅重同步与磁盘故障仍属 M3/M4/M6；不宣称跨平台验收已通过。下一包为 M2（T201–T205）。三模型的真实调用结果见 [parallel-work.md](../parallel-work.md)。
